# Task 09 - Melhorar UX para operacao ao vivo

## Objetivo

Tornar o painel mais seguro e rapido para uso durante culto, transmissao ou evento ao vivo.

## Contexto

Durante operacao ao vivo, o usuario precisa agir com rapidez e evitar cliques acidentais. Pequenas melhorias de fluxo podem reduzir bastante o risco.

## Escopo sugerido

- Adicionar botao para limpar canal atual.
- Adicionar botao para ocultar/exibir canal sem apagar texto.
- Adicionar indicador de estado por canal.
- Adicionar URLs do vMix com botao de copiar.
- Mostrar conexao do painel com backend.
- Se possivel, mostrar quantidade de displays conectados por canal.
- Manter confirmacao para acoes amplas, como enviar estilo para todos.
- Melhorar preview para parecer mais com uma saida 16:9.

## Fora de escopo

- Criar sistema de usuarios.
- Criar automacao de playlist.
- Controlar o vMix diretamente.

## Criterios de aceite

- Operador consegue limpar ou ocultar um canal rapidamente.
- URLs do vMix podem ser copiadas sem selecionar texto manualmente.
- Acoes destrutivas ou amplas possuem confirmacao.
- O painel comunica claramente qual canal esta sendo editado.
- Preview ajuda a antecipar a aparencia no vMix.
