# Task 12 - Documentar cenarios reais

## Objetivo

Adicionar documentacao pratica para instalacao e solucao de problemas em cenarios reais de uso com Holyrics, rede local e vMix.

## Contexto

O README ja cobre uso rapido e API. Uma camada de receitas operacionais ajudaria pessoas nao tecnicas a colocar tudo para funcionar no evento.

## Escopo sugerido

- Documentar uso em uma unica maquina.
- Documentar Holyrics em um PC e vMix em outro.
- Documentar painel acessado por outro dispositivo na mesma rede.
- Explicar como descobrir o IP correto.
- Explicar portas usadas: painel, backend e Holyrics.
- Adicionar troubleshooting para firewall, porta ocupada, Holyrics sem plugin, path errado e CORS.
- Adicionar checklist pre-evento.

## Fora de escopo

- Manual completo do Holyrics.
- Manual completo do vMix.
- Suporte para ambientes em nuvem.

## Criterios de aceite

- Novo usuario consegue configurar o fluxo basico seguindo a documentacao.
- Problemas comuns possuem passos de verificacao.
- URLs de exemplo deixam claro quando usar `localhost` e quando usar IP da rede.
- Checklist ajuda a validar tudo antes do inicio do evento.
